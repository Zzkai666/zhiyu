# ResearchDesk UI 概念图 · 2026-11-14

先打开 [完整画廊](./index.html)。点击图片放大，左右键切换；可按模块筛选，标记“保留方向／需要调整”，填写意见并导出文本。标记仅保存在当前浏览器，不会修改软件。

本轮只制作设计图与离线审阅画廊，没有修改正式UI、业务源码、数据库、安装包或小岛程序。正式版本仍为0.7.2。用户认可后才安排实现。

生成方式为内置 image_gen 生图工具，每个页面独立生成；设置页面参考同一框架图，若干读图后发现的细节另作非覆盖式校正。完整提示词、原始路径与最终图在 prompts-and-manifest.json。最终稿共27页；-v2是校正版，较早稿保留供比较，画廊默认展示校正版。

## 方向

暖色研究手帐：象牙白、燕麦色、杏陶色强调、低饱和鼠尾草绿。通过书签、档案页签、索引卡、章节路线和少量手绘小物增加趣味。控制装饰密度，研究内容和常用操作优先；阅读页比首页更安静。工作台使用暖色，小岛维持原生五款主题和毛玻璃材质，不跟随重涂暖色。

主要现有边界保持：任务重要日期常驻、今日独立待办；PDF连续纵向滚动；原译文默认各半、可拖比例；双向段落与多原文区域定位；就近评论和六类标注；Codex翻译；图表裁图。不恢复独立笔记、论文问答、跨语言句子匹配，不进入训练执行。

图片中的论文内容、作者、引用、日期星期、账号、天气和数字仅为排版示例，不能当作论文原文、真实数据或功能验收。自动生成文案仍有少量不精确处，实际实现须使用真实字段和业务规则；例如提醒设置只控制提示，不自动调节音量/亮度或向蓝牙设备转发消息；印章反馈应在评分后出现；控件数值仍按现有合法范围。

## 值得单独决定的增量

- 首页：更完整的课程接续与周回顾，避免只做静态装饰。
- 任务：逐事项提前提醒、清楚的侧边编辑；不因展示月历而隐藏远期日期。
- 项目：真实的活动时间线、材料分组和下一步行动视图。
- 课程：基于已保存实际记录的每周投入图，章节路线不设强制顺序。
- 词库：字母索引、发音及更直观的复习反馈，需明确音频来源与实际调度。
- 生活：可复用时长和说明的活动模板，饮水和运动使用真实记录统计。
- 设置：即时预览、字号密度、连接指引；数据位置迁移和诊断复制需另作具体实现。

这些提案尚未实现，不因出现在概念图里就自动加入开发范围。可以先选视觉方向，再逐项决定功能。
