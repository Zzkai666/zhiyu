# 知屿 · Zhiyu

2026-11-14。为 ResearchDesk Next 设计的新名称与应用图标。

名称：知屿。产品说明：阅读、学习与每日安排。名字以“知”表达知识与学习，以“屿”表达安静、属于自己的空间，呼应可选的桌面小岛。英文标识采用拼音 Zhiyu，不生造另一个英文品牌。

图标：翻开的书页与绿色岛屿合为一个主体，暖阳表达每天的积累。暖纸色、陶土色、鼠尾草绿与现有工作台协调。没有把产品名称塞进图形，小尺寸优先辨认书页与岛屿。

文件：
- zhiyu-source.png：内置 image_gen 最终生成原图。
- zhiyu-1024.png：1024 方形 PNG。
- zhiyu.ico：Windows 图标，含 16/24/32/48/64/128/256px 七个尺寸。
- zhiyu-*.png：小尺寸检查与复用。
- preview.html：亮暗背景和小尺寸预览。
- prompts.json：三轮生成/精修提示词及来源路径。
- build-icon.cjs：只做尺寸重采样及 ICO 容器封装，无创意性图像编辑。

这批为名称与图标资产交付，未改现有 0.8.1 的产品字符串、安装身份、资料路径或已验证 EXE。后续统一品牌接入应保持现有 appId、资料目录和安装组件身份，避免被当作另一个软件导致资料看似丢失。
